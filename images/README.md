# 📁 images 폴더

이 폴더에 포트폴리오에 쓸 이미지를 모두 넣어주세요.

## 네이밍 규칙
프로젝트별로 아래 형식을 따르면 관리하기 편해요:

```
프로젝트명-thumb.jpg      ← 카드 썸네일 (대표 이미지)
프로젝트명-01.jpg
프로젝트명-02.jpg
프로젝트명-03.jpg
...
```

## 예시
```
naver-thumb.jpg
naver-01.jpg
naver-02.jpg

lg-thumb.jpg
lg-01.jpg
lg-02.jpg

cheil-thumb.jpg
cheil-01.jpg
```

## 이미지 경로 사용법
포트폴리오 편집 모드에서 이미지 URL 입력란에 아래처럼 입력하세요:
```
images/파일명.jpg
```

## 주의사항
- 파일명에 **한글, 공백 사용 금지** → 영문, 숫자, `-`, `_` 만 사용
- 확장자: `.jpg` `.jpeg` `.png` `.webp` `.gif` 모두 가능
- 반드시 **Live Server** 로 실행해야 로컬 이미지가 정상 표시됨
